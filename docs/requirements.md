# PLCEmulator 機能要求一覧

> [!WARNING] **重大な実装乖離: 実通信パイプラインの未配線**
> MCプロトコルパーサー（`mc_frame_3e.py`等）やコマンド処理器（`command_processor.py`）、デバイスメモリ（`device_manager.py`）等の**単体ロジックは実装済みで単体テストもパス**していますが、**通信サーバ（`tcp_server.py` / `udp_server.py`）が受信パケットを読み捨て／pass** しており、プロトコル処理・コマンド実行・応答返送パイプラインと接続されていません。
> そのため、現状では外部TCP/UDPクライアントからの通信に対して応答が一切返りません。
> また、Webサーバ（FastAPI）とPLC通信サーバの統合起動、送受信ログのWebSocket配信も未配線です。

> **ステータス凡例**:
> - `- [x]` **完了**: 単体実装および実動可能
> - `- [ ]` **未完了 / 一部対応**: 未着手、または単体実装のみでサーバ未接続・実通信不可
>
> **最終更新**: 2026-10-08 (実通信パイプライン検証結果反映)
