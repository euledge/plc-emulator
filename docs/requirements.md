# PLCEmulator 機能要求一覧

## FR-001: MCプロトコル / SLMP 通信エミュレーション

### FR-001-1: フレームフォーマット対応
- [x] 1Eフレーム（バイナリ）の受信解析・応答生成（TCP/UDPとも対応）
- [x] 3Eフレーム（バイナリ）の受信解析・応答生成（TCP/UDPとも対応）
- [x] 3Eフレーム（ASCII）の受信解析・応答生成
- [x] 4Eフレーム（バイナリ）の受信解析・応答生成（TCP/UDPとも対応）
- [x] SLMP拡張デバイス指定（4バイトアドレス + 2バイトコード）対応

### FR-001-2: コマンド対応
- [x] `0401` 一括読出し（ワード/ビット）
- [x] `1401` 一括書込み（ワード/ビット）
- [x] `0403` ランダム読出し（ワード + ダブルワード混在）
- [x] `1402` ランダム書込み（ワード + ダブルワード混在）
- [x] `0801` モニタ登録
- [x] `0802` モニタ実行
- [x] `0101` CPU型名読出し
- [x] `1001` リモートRUN
- [x] `1002` リモートSTOP
- [x] `0619` ループバックテスト
- [ ] `1630` リモートパスワードアンロック
- [ ] `1631` リモートパスワードロック
- [x] 未サポートコマンドに対するエラーコード応答（0xC059）

### FR-001-3: デバイス対応

#### ビットデバイス
- [x] X（入力リレー, コード: 0x9C, 16進数アドレス）
- [x] Y（出力リレー, コード: 0x9D, 16進数アドレス）
- [x] M（内部リレー, コード: 0x90, 10進数アドレス）
- [x] L（ラッチリレー, コード: 0x92, 10進数アドレス）
- [x] F（アナンシエータ, コード: 0x93, 10進数アドレス）
- [x] V（エッジリレー, コード: 0x94, 10進数アドレス）
- [x] B（リンクリレー, コード: 0xA0, 16進数アドレス）
- [x] SM（特殊リレー, コード: 0x91, 10進数アドレス）
- [x] SB（リンク特殊リレー, コード: 0xA1, 16進数アドレス）
- [x] S（ステップリレー, コード: 0x98, 10進数アドレス）
- [x] TS（タイマ接点, コード: 0xC1, 10進数アドレス）
- [x] TC（タイマコイル, コード: 0xC0, 10進数アドレス）
- [x] CS（カウンタ接点, コード: 0xC4, 10進数アドレス）
- [x] CC（カウンタコイル, コード: 0xC3, 10進数アドレス）

#### ワードデバイス
- [x] D（データレジスタ, コード: 0xA8, 10進数アドレス）
- [x] W（リンクレジスタ, コード: 0xB4, 16進数アドレス）
- [x] R（ファイルレジスタ, コード: 0xAF, 10進数アドレス）
- [x] ZR（拡張ファイルレジスタ, コード: 0xB0, 16進数アドレス）
- [x] SD（特殊レジスタ, コード: 0xA9, 10進数アドレス）
- [x] SW（リンク特殊レジスタ, コード: 0xB5, 16進数アドレス）
- [x] TN（タイマ現在値, コード: 0xC2, 10進数アドレス）
- [x] CN（カウンタ現在値, コード: 0xC5, 10進数アドレス）

### FR-001-4: エミュレート対象PLC機種
- [x] Q03UDE（MELSEC-Q）
- [x] Q06UDE（MELSEC-Q）
- [x] R04CPU（MELSEC iQ-R）
- [x] R08CPU（MELSEC iQ-R）
- [x] FX5U（MELSEC iQ-F）
- [x] L06CPU（MELSEC-L）

### FR-001-5: エラーコード応答
- [x] 0x0000 正常完了
- [x] 0xC050 コマンド/応答タイプ仕様外
- [x] 0xC051 開始アドレス範囲外
- [x] 0xC056 デバイス指定エラー
- [x] 0xC058 デバイスアドレス無効
- [x] 0xC059 未サポートコマンド
- [x] 0xC05B パラメータエラー
- [x] 0xC061 データ長不一致
- [x] エラー応答の手動ON/OFF切替

---

## FR-002: 通信サーバ

### FR-002-1: 接続方式
- [x] TCP接続対応（3Eバイナリ電文の送受信に対応）
- [x] UDP接続対応（3Eバイナリ電文の送受信に対応。遅延中の未処理要求が上限に達した場合は新規電文を破棄）
- [x] TCP/UDP選択可能（稼働中の動的切替に対応）
- [x] 1クライアント接続仕様（2接続目を拒否し、通信中の接続を維持）
- [x] ポート番号設定可能（1024-65535、デフォルト: 5000）

### FR-002-2: 接続管理
- [x] クライアント切断検知（recv=0検出）
- [x] 切断後の自動クリーンアップ
- [x] 再接続対応（サーバ再起動不要）

---

## FR-003: レイテンシエミュレーション

- [x] レイテンシ無し（即座に応答）
- [x] 固定遅延（指定ミリ秒後に応答）
- [x] ランダム遅延（範囲指定）
- [x] 正規分布遅延（平均・標準偏差指定）
- [x] タイムアウト模擬（確率指定で応答しない）
- [x] レイテンシはMCプロトコル/SLMP応答にのみ適用（Web UIには適用しない）
- [x] 遅延統計表示（平均・最大・最小）

---

## FR-004: デバイスメモリ管理

### FR-004-1: 基本機能
- [x] デバイス値の読み書き
- [x] ビットデバイスの16ビットワード内パッキング
- [x] PLC機種に応じたデバイスレンジチェック

### FR-004-2: Web UIからの値設定
- [x] 画面上でデバイス値を直接編集（設定した値を通信で使用）
- [x] デバイス値の一括クリア

### FR-004-3: 永続化
- [x] デバイス値のJSON形式での保存
- [x] デバイス値のJSON形式での読込（復元）

---

## FR-005: デバイスメモリスクリプトエンジン

### FR-005-1: DSL仕様
- [x] YAMLベースのスクリプト定義
- [x] 周期実行（periodic）: 一定間隔でデバイス値を更新
- [x] 条件実行（conditional）: デバイス値に基づく分岐
- [x] シーケンス実行（sequence）: ステップ順次実行
- [x] ランプ（ramp）: 値の段階的変化

### FR-005-2: 式評価
- [x] 数学関数: sin, cos, abs, min, max, floor, ceil, int
- [x] 範囲制限: clamp(x, lo, hi)
- [x] 乱数: random(), randint(a, b)
- [x] 波形生成: square(t, period), triangle(t, period), sawtooth(t, period)
- [x] デバイス値参照（式内で D100, M0 等を変数として使用）
- [x] 組み込み変数: t（経過秒）, dt（前回からの経過）, tick（実行回数）

### FR-005-3: 安全性
- [x] ast.parseベースのサンドボックス式評価（eval/exec不使用）
- [x] ファイルシステム・ネットワークアクセス不可
- [x] import文不可
- [x] 評価タイムアウト

### FR-005-4: スクリプト管理
- [x] スクリプトの開始/停止/一時停止
- [x] プリセットシナリオ（テンプレート提供）
- [x] バリデーション（YAML構文 + 式の安全性チェック）

---

## FR-006: Web UI

### FR-006-1: サーバ設定画面
- [x] プロトコル選択: MCプロトコル 3E / 1E / 4E / SLMP
- [x] 通信方式選択: TCP / UDP
- [x] ポート番号入力
- [x] データ形式選択: Binary / ASCII
- [x] PLC機種選択
- [x] エラー応答 ON/OFF
- [x] レイテンシ設定

### FR-006-2: デバイスモニタ
- [x] デバイス種別タブ切替（D, M, X, Y, W, R等）
- [x] 開始アドレス指定
- [ ] 表示形式切替: DEC符号なし / DEC符号付き / HEX / BIN / FLOAT / ASCII（DEC, HEX, BINのみ対応）
- [x] ダブルクリックで値を直接編集
- [x] WebSocketによるリアルタイム更新

### FR-006-3: 通信ログ
- [x] タイムスタンプ + 方向（TX/RX）+ HEXダンプ
- [ ] 解析済みコマンド名表示
- [x] 自動スクロール ON/OFF
- [ ] ログクリア・テキスト保存（ログクリアのみ対応、テキスト保存未対応）

### FR-006-4: スクリプトエディタ
- [ ] YAMLテキストエディタ（シンタックスハイライト付き）
- [x] スクリプト開始/停止/一時停止ボタン
- [x] 実行中ステータス表示
- [ ] プリセットテンプレート選択
- [x] バリデーション結果表示

## NFR-001: 非機能要求

### NFR-001-1: クロスプラットフォーム
- [x] Windows, macOS, Linux で動作
- [x] 特別な開発環境不要（Python + ブラウザのみ）

### NFR-001-2: パフォーマンス
- [x] ベースレスポンスタイム 50ms 以内（レイテンシエミュレーション無効時）
- [x] デバイスメモリアクセス O(1)
- [x] スクリプトエンジンがプロトコル応答をブロックしない

### NFR-001-3: 国際化（i18n）
- [x] 日本語対応
- [x] 英語対応
- [x] JSONベースの翻訳ファイル
- [x] 動的言語切替

### NFR-001-4: マニュアル忠実性
- [x] 三菱電機公式マニュアル（SH-080008等）に準拠したプロトコル実装
- [x] デバイスコード、コマンドコード、エラーコードは公式仕様に忠実
