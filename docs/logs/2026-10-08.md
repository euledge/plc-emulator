#### 2. スクリプトエンジンの機能拡充・ビット書き込み対応 (`81fa58f`)
- **実践的シミュレーションサンプルの追加**:
  - `scripts/` および `scripts/examples/` 配下に6種類の産業用シミュレーションシナリオを追加（合計9種類）:

  - ビットデバイスへの書き込み時に `write_word` ではなく `write_bit` を呼び出すよう修正。
  - 複数文字のデバイス種別（SM, SB, TS, TC, CS, CC, TN, CN, SD, SW, ZR）の正規表現パースとアクセスに対応。
- **テスト拡充**:
  - `tests/test_script_engine.py` にシーケンス実行テストおよび全サンプルスクリプトのロード・実行テストを追加。

#### 3. TCP MC 3E バイナリ通信の本格実装と Issue #1 対応 (`a6aa314`, `48e2f5a`, `4d93e59`, PR #30)
- **TCP MC 3E 電文処理の実装 (`a6aa314`)**:
  - `src/server/tcp_server.py` にて 3E バイナリ電文（サブヘッダ `0x0050`）の抽出・解析・応答生成ループを実装。
  - `CommandProcessor` および `DeviceManager` との接続、通信ログ（RX/TX）コールバック、`LatencyEmulator` による遅延・タイムアウト模擬適用を統合。
- **通信堅牢性と接続維持の修正 (`48e2f5a`)**:
  - 不完全な書き込み電文の拒絶および応答長超過時のパラメータエラー（`0xC05B`）返却。
  - 3E 要求電文のアクセス経路情報（ネットワーク番号、PC番号、要求先ユニットI/O番号、要求先ユニット局番号: `access_path`）を保持して応答に反映。
  - **1クライアント接続仕様の厳格化**: 通信中のアクティブ接続が存在する場合、2つ目以降の接続要求を即時クローズしつつ既存セッションを維持するよう修正。
  - クライアント切断（`recv=0` / EOF）検知と `finally` 句でのリソース自動クリーンアップ。
- **コード整形 (`4d93e59`)**:
  - `src/server/tcp_server.py` の末尾余分な空行を削除。
- **テスト拡充**:
  - `tests/test_tcp_server.py` に同一接続での読書、競合クライアント拒否、切断後の再接続、不完全フレーム処理、レイテンシ適用などの包括的なリグレッションテストを追加。
- **要件・タスク管理の反映**:
  - `docs/requirements.md` および `docs/tasks.md` における TCP 3E 通信および関連項目のステータスを更新。
- **プルリクエストマージ (`6b4974b`)**:
  - PR #30 (`issue-1-tcp-3e-clean-pr`) をレビュー・マージ（Closes #1）。

#### 4. UDP MC 3E バイナリ通信の実装と Issue #2 対応 (`22d8993`, `f14db5d`, PR #31)
- **UDP 3E 電文処理の実装 (`22d8993`)**:
  - `src/server/udp_server.py` にて `asyncio.DatagramProtocol` を用いた MC 3E バイナリ要求の受信解析および送信元への応答送信を実装。
  - TCP と同様に `DeviceManager` の共有メモリへの読み書き、`CommandProcessor` での電文処理、`LatencyEmulator` による遅延・タイムアウト模擬適用を統合。
- **通信堅牢性と過負荷保護 (`f14db5d`)**:
  - 無関係な不正データグラムはエラー返却せず無視（DoS防止）。
  - 宣言データ長不一致時のエラー返却（`0xC061`）およびメモリ不変更保護。
  - IPv4 UDP ペイロード上限を超える読出し応答要求に対するパラメータエラー（`0xC05B`）返却。
  - 遅延洪水時の未処理要求数を最大128件に制限し、超過時の新規電文破棄でメモリ枯渇を防止。
- **テスト拡充**:
  - `tests/test_udp_server.py` に UDP 実ソケットを用いた読書・不正長・サイズ超過・遅延・タイムアウト検証を追加。
- **プルリクエストマージ**:
  - PR #31 (`issue-2-udp-3e-clean-pr`) をマージ（Closes #2）。

#### 5. PLC サーバと Web UI の共有起動・ライフサイクル管理と Issue #3 対応 (`b6b6c23`, `685e0c4`, `d45347a`, `ca0e5cf`, PR #32)
- **1プロセス共有実行 (`b6b6c23`, `main.py`)**:
  - 単一の `PLCEmulatorApp` 内で TCP/UDP 通信サーバと FastAPI Web UI（Uvicorn）を並行稼働。
  - 同一の `ConfigManager`, `DeviceManager`, `LatencyEmulator`, `WebSocketManager`, `PersistenceManager` を参照させ、REST API と PLC ソケット通信間でのメモリリアルタイム共有を実現。
- **セキュリティ・ポート競合ロールバック (`d45347a`)**:
  - Web API のデフォルトバインド先を安全なローカルホスト（`127.0.0.1`）に変更。
  - Web ポート衝突時に `OSError` を検知し、既に起動した PLC サーバをクリーンにロールバック停止。
- **堅牢なシャットダウン順序制御 (`685e0c4`, `ca0e5cf`)**:
  - Web サーバの予期せぬ終了時に PLC サーバを自動停止。
  - 全共有サービスの停止完了後に `stopped` シグナルを発火し、重複停止処理を防止。
- **テスト拡充**:
  - `tests/test_shared_app.py` に同時起動、HTTP 書込み後の TCP/UDP 読出し、ポート競合ロールバック、二重停止防止などの結合テストを追加。
- **プルリクエストマージ**:
  - PR #32 (`issue-3-shared-startup`) をマージ（Closes #3）。

#### 6. 稼働中通信サーバへの Web 設定動的反映と Issue #4 対応 (`a85eac8`, `7d25b21`, `8920591`, PR #33)
- **設定の動的適用 (`a85eac8`, `src/web/api_routes.py`, `static/js/settings.js`)**:
  - Web UI の Settings パネルからの設定変更（PLC 機種、通信プロトコル、トランスポート、ポート、レイテンシ設定）を稼働中の PLC 通信サーバに即時反映。
  - 6機種プロファイル（Q03UDE, Q06UDE, R04CPU, R08CPU, FX5U, L06CPU）の切替と CPU 型名・アドレス範囲チェックの即時更新。
  - TCP ⇔ UDP のトランスポート切替およびポート変更時に、アクティブセッションを適切にクローズして新トランスポートで再起動。
- **設定バリデーションと未対応機能のエラー返答 (`7d25b21`)**:
  - 未実装のプロトコル（1E, 4E, SLMP）や ASCII フォーマット指定時、偽りの成功を返さず HTTP 400 エラーを返却して現在の設定を保護。
  - 設定変更失敗時に設定パネルにエラーメッセージを表示。
- **テスト拡充**:
  - `tests/test_dynamic_config.py` に機種切替後の電文検証、TCP/UDP 切替、レイテンシ動的変更、無効設定ロールバックなどの自動テスト（465行）を追加。
- **プルリクエストマージ**:
  - PR #33 (`issue-4-dynamic-web-config`) をマージ（Closes #4）。
