# PLCEmulator 作業ログ

### 概要
v0.1.0 リリース後のドキュメント整備、スクリプトエンジンのシミュレーション機能拡充およびビット書き込み対応、Issue #1 に対応する TCP MC 3E バイナリ通信の本格実装・接続維持と検証を実施。

### 作業内容詳細

#### 1. ドキュメント整備とテスト実行環境の改善 (`f6a90da`)
- **pytest 設定の最適化**:
  - `pyproject.toml` に `addopts = "--ignore=tests/test_e2e.py"` を追加し、通常の `uv run pytest` 実行時にヘッドレスブラウザが必要な E2E テストをデフォルトで除外（テスト実行の高速化と CI 安定化）。
- **README / リリースノート整備**:
  - `README.md` および `README.ja.md` にユニットテストと E2E テストの実行手順、クイックスタートコマンドを追記・明確化。
  - 日本語版リリースノート `RELEASE_NOTES_v0.1.0.ja.md` を作成し、英語版との相互リンクを追加。
- **ドキュメントアセットの追加**:
  - FastAPI から OpenAPI スキーマをエクスポートし `docs/openapi.json` を生成・配置。
  - Web ダッシュボードのスクリーンショット `docs/images/dashboard-screenshot.png` を配置。
  - ツールキャッシュの除外と docs 用 JSON ファイルのトラッキングを `.gitignore` に反映。

#### 2. スクリプトエンジンの機能拡充・ビット書き込み対応 (`81fa58f`)
- **実践的シミュレーションサンプルの追加**:
  - `scripts/` および `scripts/examples/` 配下に6種類の産業用シミュレーションシナリオを追加（合計9種類）:
    - `heartbeat.yaml`: ハートビート監視信号
    - `sensor_simulation.yaml`: センサー値変動
    - `alarm_interlock.yaml`: アラーム連動インターロック
    - `cylinder_sequence.yaml`: シリンダー前後進シーケンス
    - `tank_level_control.yaml`: タンク液位制御
    - `traffic_light.yaml`: 信号機制御シーケンス
- **ScriptEngine の機能修正**:
  - ビットデバイスへの書き込み時に `write_word` ではなく `write_bit` を呼び出すよう修正。
  - 複数文字のデバイス種別（SM, SB, TS, TC, CS, CC, TN, CN, SD, SW, ZR）の正規表現パースとアクセスに対応。
- **テスト拡充**:
  - `tests/test_script_engine.py` にシーケンス実行テストおよび全サンプルスクリプトのロード・実行テストを追加。

#### 3. TCP MC 3E バイナリ通信の本格実装と Issue #1 対応 (`a6aa314`, `48e2f5a`, `4d93e59`, PR #30)
- **TCP MC 3E 電文処理の実装 (`a6aa314`)**:
  - `src/server/tcp_server.py` にて 3E バイナリ電文（サブヘッダ `0x0050`）の抽出・解析・応答生成ループを実装。
  - `CommandProcessor` および `DeviceManager` との接続、通信ログ（RX/TX）コールバック、`LatencyEmulator` による遅延・タイムアウト模擬適用を統合。
- **通信堅牢性と接続維持の修正 (`48e2f5a`)**:
  - 不完全な書き込み電文の拒絶および応答長超過時のパラメータエラー（`0xC05B`）返却。
  - 3E 要求電文のアクセス経路情報（ネットワーク番号、PC番号、要求先ユニットI/O番号、要求先ユニット局番号: `access_path`）を保持して応答に反映。
  - **1クライアント接続仕様の厳格化**: 通信中のアクティブ接続が存在する場合、2つ目以降の接続要求を即時クローズしつつ既存セッションを維持するよう修正。
  - クライアント切断（`recv=0` / EOF）検知と `finally` 句でのリソース自動クリーンアップ。
- **コード整形 (`4d93e59`)**:
  - `src/server/tcp_server.py` の末尾余分な空行を削除。
- **テスト拡充**:
  - `tests/test_tcp_server.py` に同一接続での読書、競合クライアント拒否、切断後の再接続、不完全フレーム処理、レイテンシ適用などの包括的なリグレッションテストを追加。
- **要件・タスク管理の反映**:
  - `docs/requirements.md` および `docs/tasks.md` における TCP 3E 通信および関連項目のステータスを更新。
- **プルリクエストマージ (`6b4974b`)**:
  - PR #30 (`issue-1-tcp-3e-clean-pr`) をレビュー・マージ。
