### 作業内容詳細

#### 1. エラー応答の有無を設定・切替可能にする (Issue #5, PR #34)
- `ConfigManager` に `error_response_enabled: bool = True` を追加。
- `TcpServer` および `UdpServer` でエラー発生時に無応答とする動作モードをサポート。
- Web UI 設定画面（Settings）に「Error Response」チェックボックスを追加し、動的切替に対応。
- `tests/test_error_response_toggle.py` を追加して検証。

#### 2. モニタ登録・モニタ実行コマンド対応 (Issue #6, PR #35)
- MCプロトコル `0x0801`（モニタ登録）および `0x0802`（モニタ実行）を `CommandProcessor` に実装。
- 登録されたデバイスリストに基づき、`0802` で一括値取得を行う仕組みを構築。
- `tests/test_monitor_commands.py` を追加して検証。

#### 3. MCプロトコル 3Eフレーム ASCIIモード対応 (Issue #7, PR #36)
- サブヘッダ `5000`（要求）および `D000`（応答）の ASCII 16進テキスト送受信ハンドラを実装。
- ASCIIとバイナリの自動判別および相互運用性を確保。
- `tests/test_mc_frame_3e_ascii.py` を追加して検証。

#### 4. 1Eフレームのバイナリ通信対応 (Issue #8, PR #37)
- MCプロトコル 1E フレームハンドラ（サブヘッダ `0x00`〜`0x03` 要求、`0x80`〜`0x83` 応答）を実装。
- ビット・ワードの一括読出し・書込み、複数機種アドレス体系の整合性を確保。
- `tests/test_mc_frame_1e.py` を追加して検証。

#### 5. 4Eフレームのバイナリ通信対応 (Issue #9, PR #38)
- サブヘッダ `0x5400`（要求）および `0xD400`（応答）の 4E フレームハンドラを実装。
- シリアル番号フィールドの管理および応答への正確なエコーバックを保証。
- `tests/test_mc_frame_4e.py` を追加して検証。

#### 6. リモートRUN・STOPコマンド対応 (Issue #10, PR #39)

- `tests/test_remote_run_stop.py` を追加して検証。

#### 7. ビット単位のサブコマンド対応 (Issue #11, PR #40)

#### 23. 1630/1631 リモートパスワード解除・ロック対応 (Issue #27, PR #56)
- MCプロトコル `0x1630`（パスワードアンロック）および `0x1631`（パスワードロック）コマンドを実装。
- パスワード不一致時は `0x4A01`（`REMOTE_PASSWORD_MISMATCH`）を返却。
- ロック状態での書込み要求（0x1401, 0x1402, 0x1001, 0x1002等）を `0x4A03`（`REMOTE_PASSWORD_LOCKED`）で拒否。
- 通信ログにおいてパスワードペイロードを `**` でマスク。
- ソケット再接続時にロック状態が復元されるセッション安全性を担保。
- `tests/test_remote_password.py` を追加して検証。

- 組み込み変数（`t`, `dt`, `tick`）、数学関数（`sin`, `cos`, `clamp` 等）、波形生成関数、デバイス直接参照、禁止構文を明記。
- 記載されている全 YAML サンプルが `ScriptParser` のバリデーションを通過することを `tests/test_dsl_reference.py` で検証。
- `docs/tasks.md` および `docs/tasks/task.md` の Phase 6 チェック欄を更新。
